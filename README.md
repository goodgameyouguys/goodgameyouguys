# Kyle Thormodsgaard

I turn ideas into working software with Claude Code: MCP servers, integrations, and full web apps. Give me a problem and I'll find a way to build the thing that solves it.

## Projects

- **Mac Bridge:** A suite of MCP servers that connects Claude to the Mac apps people use every day. Claude can manage events in Calendar, read, search, and send iMessages, and create, search, and edit Apple Notes.
- **fal-mcp:** An MCP server that gives Claude a full creative toolkit through fal.ai: image and video generation, image editing, background removal, and upscaling.
- **Remote Job Search Tracker:** A live, database-backed web app for tracking applications across remote job boards.

## How I build

- **Ideation:** Every project here started as friction in my own day: an assistant that couldn't see my calendar or messages, or a job search too scattered to track. I brainstorm openly, sketch out a few approaches, and pressure-test the idea before writing any code.
- **Claude Code & MCP:** I design and ship tools with Anthropic's Claude Code, connecting Claude to the apps and services people already use.
- **Idea to working product:** I scope the problem, build it, test it, and keep iterating until it's genuinely useful day to day.
- **Beyond software:** I also design in CAD (Fusion 360, SketchUp, Rhino) and build in my own metal and wood shop. If it can be made, I'll figure out how.
